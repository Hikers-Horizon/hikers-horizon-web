Swift Seat Privacy Policy
OFFICIAL PRIVACY DISCLOSURE & DATA COMMITMENT
Effective Date: July 31, 2026 App Version: 2.0.0

This Privacy Policy outlines how Swift Seat Mobile Bot ("Swift Seat", "we", "our", or "us") manages and protects your privacy when using our browser extension, web application, and mobile automation system.

1. Single Purpose & Scope

Swift Seat is built with a single, narrow purpose: to assist users in completing time-sensitive ticket booking forms on authorized portals (such as IRCTC Next Generation train booking and Aranya Vihaara Karnataka forest trek permits). The system automates local passenger detail autofill, station selection, and countdown synchronization.

2. Local On-Device Data Storage

All sensitive user information—including passenger names, ages, gender preferences, journey parameters, train numbers, and login credentials—is stored 100% LOCALLY ON-DEVICE inside your web browser using chrome.storage.local.

  • No Cloud Sync of Credentials: Your IRCTC login passwords and passenger profiles are never uploaded, stored, or transmitted to any developer-owned cloud database.
  • Full Local Control: You can clear all saved credentials and data at any time by clicking the "RESET CONFIG" button in the extension popup.

3. External API & Licensing Communication

The extension communicates with external servers solely for license key activation and subscription verification via HTTPS requests to our server domain (https://swiftseat.shop/api/activate-license).

  • Data Transmitted: License Key string and an anonymous local device UUID.
  • Data Excluded: Zero personal identification data, browsing history, form content, or credentials are sent during license checks.

4. Declaration of Browser Permissions

Swift Seat requests only the minimal set of Manifest V3 browser permissions necessary for functionality:

  • storage: Retains your booking form parameters locally on your computer for instant execution.
  • activeTab: Allows form detection and autofill execution strictly when you navigate to supported booking websites and launch automation.
  • host_permissions: Restricts API network communication exclusively to license verification servers (swiftseat.shop).

5. Remote Code Policy

Swift Seat strictly complies with Chrome Web Store and Microsoft Edge Partner Center Manifest V3 Developer Policies. No remote code, external scripts, or dynamic code evaluations (eval) are executed. All extension execution logic is statically bundled inside the audited extension package.

6. Information Sharing & Third-Party Disclosure

We do NOT sell, trade, rent, or transfer user data to third parties under any circumstances. We do not use collected device IDs for tracking across unrelated websites, advertising, or creditworthiness evaluation.

7. Data Security

We employ robust AES encryption standards for license verification calls over HTTPS/TLS protocols to ensure secure communication between your browser and our licensing server.
